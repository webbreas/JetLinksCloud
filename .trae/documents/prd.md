# JetLinks Cloud 官网首页 - 产品需求文档

## 1. 产品概述

JetLinks Cloud 是一款全链路 SaaS 物联网平台，致力于为企业提供极速上线、降本增效的数字化转型解决方案。平台整合 AI 智能分析、物联设备连接、视频监控联动与数据可视化能力，帮助企业从传统设备管理平滑过渡到智能化运营。

- **核心价值**：连接无界，触手可及；告别繁琐开发，按需订阅，零代码快速构建
- **目标用户**：需要数字化转型的企业用户，尤其是工业制造、智慧城市、安防监控等领域
- **市场定位**：企业级物联网 SaaS 平台领导者，已服务超过 350 家企业用户

## 3. Three.js 3D 场景设计

### 3.1 各板块 3D 效果规划

| 板块 | 3D 效果类型 | 描述 |
|-----|------------|------|
| Hero | 数据流/连接网络 | 粒子系统形成网络连接，数据节点流动 |
| 优势展示 | 3D 图标/几何体 | 每个卡片区域有悬浮的 3D 几何装饰 |
| 人工智能 | 神经网络/粒子云 | 模拟神经网络的数据流动效果 |
| 物联板块 | 3D 地图/设备节点 | 可交互的 3D 世界地图，设备节点分布 |
| 视联板块 | 摄像头网络/视频流 | 摄像头视角的 3D 网格，模拟视频连接 |
| 可视化板块 | 3D 数据图表 | 悬浮的数据柱状图/折线图 |

### 3.2 3D 技术规范

- **渲染引擎**：Three.js r150+
- **后期处理**：UnrealBloomPass（发光效果）、FXAA（抗锯齿）
- **性能目标**：60FPS，WebGL 2.0 支持
- **动画类型**：粒子动画、几何体动画、材质过渡
- **交互**：滚动触发动画、鼠标悬停效果

## 4. 用户界面设计

### 4.1 设计风格
- **整体风格**：科技感、未来感、数字孪生美学
- **设计语言**：渐变 + 玻璃拟态 + 暗色主题
- **视觉层次**：深邃背景 + 霓虹发光 + 玻璃卡片

### 4.2 配色方案

```css
:root {
  --primary-gradient: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
  --accent-cyan: #00d4ff;
  --accent-purple: #a855f7;
  --accent-green: #10b981;
  --bg-dark: #030712;
  --bg-card: rgba(17, 24, 39, 0.8);
  --text-primary: #ffffff;
  --text-secondary: #9ca3af;
  --glass-border: rgba(255, 255, 255, 0.1);
}
```

### 4.3 字体选择
- **标题字体**：Noto Sans SC / 思源黑体 (Bold/Medium)
- **正文字体**：Noto Sans SC (Regular)
- **英文/数字**：Inter / Space Grotesk

### 4.4 动效设计
- **入场动画**：渐入 + 上移，交错延迟 100ms
- **悬停效果**：缩放 1.02，边框发光增强
- **3D 场景**：持续微动画，滚动触发表情动画
- **过渡时长**：300-500ms，ease-out 曲线

### 4.5 响应式策略
- **桌面端**：1920px 最佳显示，1440px 适配
- **平板端**：768px - 1024px，简化 3D 效果
- **移动端**：< 768px，禁用复杂 3D，改用 CSS 动画替代

## 5. 技术实现要求

### 5.1 技术栈
- **框架**：React 18 + Vite
- **样式**：Tailwind CSS 3
- **3D**：Three.js + @react-three/fiber + @react-three/drei
- **动画**：Framer Motion
- **图标**：Lucide React

### 5.2 性能优化
- 3D 场景懒加载
- 图片懒加载
- 组件代码分割
- GPU 加速动画

### 5.3 无障碍
- 键盘导航支持
- ARIA 标签
- 颜色对比度符合 WCAG AA 标准
