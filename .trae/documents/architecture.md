## 5. Three.js 3D 场景详细设计

### 5.1 Hero 背景场景 (HeroBackground)

```
场景类型: 粒子系统 + 连接线网络
功能描述:
  - 数千个发光粒子漂浮在深色背景中
  - 粒子间自动生成连线，形成动态网络
  - 粒子颜色渐变：青色 → 紫色
  - 鼠标移动影响粒子流动方向
  - 整体缓慢旋转，营造太空感
技术实现:
  - BufferGeometry 存储粒子位置
  - LineSegments 绘制连线
  - Points 渲染粒子
  - 自定义着色器实现发光效果
```

### 5.2 AI 粒子神经网络 (AIParticles)

```
场景类型: 神经网络可视化
功能描述:
  - 模拟神经元节点与突触连接
  - 数据包沿连线流动动画
  - 节点闪烁效果表示数据处理
  - 滚动到该区域触发动画启动
技术实现:
  - SphereGeometry 作为神经元节点
  - TubeGeometry 或 Line 作为突触
  - InstancedMesh 优化大量节点渲染
  - 后期处理 UnrealBloomPass 发光
```

### 5.3 设备地图场景 (DeviceMap)

```
场景类型: 3D 世界地图 + 设备节点
功能描述:
  - 简化地球或中国地图几何体
  - 设备位置以发光点标记
  - 脉冲波纹效果表示数据传输
  - 可选：设备详情悬停显示
技术实现:
  - 自定义地图几何或 PlaneGeometry
  - Points 渲染设备节点
  - RingGeometry 或 Sprite 实现脉冲效果
```

### 5.4 摄像头网络 (CameraNetwork)

```
场景类型: 摄像头视角网格
功能描述:
  - 多个摄像头图标分布在 3D 空间
  - 模拟视频画面窗口
  - 连接线表示视频流传输
  - 动态噪点效果模拟视频
技术实现:
  - InstancedMesh 渲染多个摄像头图标
  - PlaneGeometry 模拟视频窗口
  - ShaderMaterial 实现噪点效果
```

### 5.5 3D 数据图表 (DataChart3D)

```
场景类型: 悬浮数据可视化
功能描述:
  - 3D 柱状图/折线图悬浮展示
  - 数据动态增长动画
  - 渐变色填充
  - 网格背景增强立体感
技术实现:
  - BoxGeometry 组合实现柱状图
  - LineGeometry 实现折线
  - GridHelper 提供网格背景
```

## 6. 性能优化策略

| 优化项 | 实现方案 |
|-------|---------|
| 3D 懒加载 | 使用 React.lazy + Suspense 按需加载 3D 场景 |
| 帧率控制 | OrbitControls 设置 maxSpeed，移动端降低粒子数量 |
| 材质优化 | 共享材质球，使用 InstancedMesh |
| 内存管理 | 组件卸载时正确 dispose 几何体和材质 |
| 渲染策略 | 移动端降级为 CSS 动画，桌面端完整 3D |
| 代码分割 | 每个 Section 独立打包，按需加载 |

| 断点 | 屏幕宽度 | 3D 效果 | 布局 |
|-----|---------|--------|------|

| Desktop | 1440px - 1919px | 完整效果，标准粒子数 | 多列布局 |
| Tablet | 768px - 1439px | 简化效果，降低粒子数 | 双列布局 |
